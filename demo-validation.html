参考信息

状态 API 一览

API返回值用途
heat.isReady()boolean检查 canvas 是否有有效尺寸
heat.hasPendingDraw()boolean检查是否有待执行的绘制
heat.hasData()boolean检查是否有数据
heat.getCanvasSize()object获取当前和之前的尺寸

resize() 参数行为

调用方式行为
heat.resize()智能：从 0→有效尺寸 且 有待绘制 → 自动重绘
heat.resize(true)强制：resize 后立即重绘
heat.resize(false)从不：只同步尺寸，不重绘
heat.refresh()便捷：resize(true) + draw()
